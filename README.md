# PHP Blog

Простой блог на чистом PHP (без фреймворков), Smarty и MySQL.

Стек: PHP 8.1+, Smarty, MySQL.

## Быстрый старт (черновик)

1. `cp .env.example .env` — при необходимости поправь доступы к БД
2. `composer install`
3. Дальше: миграция схемы, сиды, Docker — появятся по мере готовности проекта
